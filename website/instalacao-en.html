Installation

How to install Trioio on Windows, macOS and Linux, what to do the first time you open it and how to solve the most common problems.

Before you start

The packages are under Download, on the home page, and on the GitHub releases page. The Windows and macOS security warnings are expected and appear only the first time.

Windows

  1. Download trioio-<version>-win64.exe and open it.
  2. Windows shows "Windows protected your PC": click "More info", then "Run anyway".
  3. If Windows asks for administrator permission, click "Yes".
  4. Click "Next" to the end. Trioio is then in the Start menu and on the desktop.

Without installing: unzip trioio-<version>-win64.zip and open Trioio.exe, with the data folder next to it.

macOS

  1. Download trioio-<version>-Darwin.dmg. It works on Intel and Apple Silicon Macs.
  2. Open it and drag Trioio into Applications.
  3. Open Trioio. The first time, macOS blocks it, because the app is signed ad hoc, without a paid Apple Developer ID. Click "OK".
  4. Allow the app once: in System Settings → Privacy & Security, click "Open Anyway" and confirm. On macOS 14 or earlier: right-click the app in Finder → Open → Open.

If the button does not appear, use Terminal. It removes the quarantine mark macOS puts on every downloaded file:

xattr -dr com.apple.quarantine "/Applications/Trioio.app"

Linux

  • Ubuntu 22.04+, Debian 12+, Mint 21+: double-click the .deb, or sudo apt install ./trioio-<version>-Linux.deb.
  • Other distributions, AppImage: make it executable (Properties → allow executing, or chmod +x) and open it.
  • Other distributions, .tar.gz: unpack it and run ./install.sh. It installs for your user, without root; ./install.sh --remove undoes it.

The first time you open it

  1. Choose a data folder with open data folder…. Your recordings, responses, judgements and memory live there. A response with stems takes a few hundred MB, so choose a disk with room.
  2. The TUTORIAL button, next to ABOUT, explains the instrument step by step, in the interface language.
  3. Trioio composes offline. The online word lookup box is the only one that uses public services (Wikidata, Datamuse), and it starts switched off.

Troubleshooting

It opens in demonstration mode and does not composechoose the data folder with open data folder…; Trioio remembers it
It does not compose on my recordinga new recording starts as pending: click authorise…, declare its origin and click authorise
No soundTrioio plays through the system's default audio output: choose the output in the sound settings, reopen Trioio and check the master
It seems frozen while composingthe bar at the bottom shows each stage and the time; a response takes from a few seconds to about a minute
Linux: the window does not openinstall the .deb with apt, which brings the dependencies; for the AppImage, install libfuse2 or start it with --appimage-extract-and-run

For anything else, write to rasgo.instruments@gmail.com with your system, the version, what you did and the message you saw.

Requirements

WindowsWindows 10 or 11, 64-bit
macOS10.15 or later, Intel and Apple Silicon
Linuxx86-64 with glibc 2.35 or newer (2022+ distributions)
Processor64-bit, two cores or more; measured on an Intel Core i5-6500: about 20 s per response, using about one core
Memoryabout 250–500 MB while composing; 4 GB in the computer is enough
Diskabout 25 MB for the app; the responses go to the data folder
